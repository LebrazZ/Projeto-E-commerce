# 🛒 Projeto E-commerce

Um sistema de e-commerce desenvolvido para praticar conceitos de desenvolvimento web utilizando **HTML**, **CSS** e **JavaScript**, com persistência de dados através do **LocalStorage**.

## 🚀 Funcionalidades

* Página inicial moderna
* Catálogo de produtos
* Pesquisa de produtos
* Filtro por categorias
* Página de detalhes do produto
* Carrinho de compras
* Favoritos
* Cadastro e login (simulado)
* Histórico de pedidos
* Painel administrativo
* Controle de estoque
* Layout responsivo

## 🛠️ Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript (ES6+)
* LocalStorage
* Git
* GitHub

## 🎯 Objetivo

Este projeto tem como objetivo aprimorar conhecimentos em desenvolvimento front-end, manipulação do DOM, organização de código, persistência de dados com LocalStorage e boas práticas de programação.

## 📌 Funcionalidades Futuras

* API em ASP.NET Core
* Banco de dados SQL Server
* Autenticação JWT
* Integração com sistema de pagamento
* Área do administrador com dashboard
* Upload de imagens
* Cálculo de frete

## ▶️ Como executar

1. Clone este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` em seu navegador.
